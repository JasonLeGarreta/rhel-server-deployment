# RHEL Server Deployment and Administration

**Status:** In Progress  
**Project Type:** Linux System Administration Home Lab  
**Platform:** Red Hat Enterprise Linux (RHEL)  
**Virtualization:** VirtualBox  
**Certification:** Red Hat Certified System Administrator (RHCSA)

## Project Overview

Designed to simulate the deployment of a Red Hat Enterprise Linux server for an internal business application team.

This project demonstrates practical Linux system administration skills through server configuration, user management, storage administration, network services, security hardening, and system troubleshooting.

The objective is to build a functional, secure, and maintainable Linux server while documenting implementation procedures and verification results.

## Business Scenario

An organization requires a Linux server to support an internal application environment. The server must provide secure administrative access, reliable storage, controlled network access, and the ability to host an internal web service.

I am responsible for deploying, configuring, securing, and validating the server.

## Project Objectives

### 1. Server Deployment
- Configure hostname and network settings.
- Verify network connectivity and name resolution.
- Configure software repositories and package management using DNF.

### 2. User and Access Management
- Create administrative users and groups.
- Configure sudo permissions.
- Configure SSH remote administration.
- Apply appropriate file and directory permissions.

### 3. Storage Administration
- Create and manage partitions and LVM volumes.
- Configure filesystems.
- Create persistent mounts using UUIDs and `/etc/fstab`.
- Verify storage availability after reboot.

### 4. Network Services
- Install and configure Apache HTTP Server.
- Configure service startup using systemd.
- Verify web service availability.

### 5. Security Configuration
- Configure SELinux policies and file contexts.
- Configure firewalld rules.
- Validate access permissions and service security.

### 6. System Administration and Troubleshooting
- Inspect system logs using journalctl.
- Manage and troubleshoot systemd services.
- Write Bash scripts for basic system checks.
- Document configuration issues and resolutions.

## Implementation and Verification

Each completed objective will include:

- Configuration steps and commands.
- Relevant configuration files.
- Verification commands and results.
- Screenshots demonstrating successful implementation.
- Troubleshooting notes where applicable.

## Skills Demonstrated

Red Hat Enterprise Linux, Linux System Administration, Bash, SSH, DNF, User and Group Management, LVM, Filesystems, Apache, SELinux, firewalld, systemd, and Linux Troubleshooting.

## Project Structure

Documentation, scripts, configuration examples, and verification evidence will be organized within this repository as the project develops.
